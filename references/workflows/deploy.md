# Workflow: deploy

Prepares static files for automated or manual deployment across free and shared hosts (GitHub Pages, Cloudflare Pages, Netlify, cPanel).

---

## Steps

1. **Verify Asset & Path Integrity**:
   - Ensure all `src` and `href` links use clean relative paths.

2. **Generate Deploy Config**:
   - Provide GitHub Actions workflow (`.github/workflows/static.yml`) or `.htaccess` for cPanel caching.

3. **Pre-Emit Self-Critique**:
   - `/* Pre-emit critique: P5 H5 E5 S5 R5 V5 D5 */`

---

## Validation checklist

- [ ] All file paths verified as clean relative paths.
- [ ] Deploy instructions provided for selected hosting provider.
- [ ] Pre-emit critique stamp included.

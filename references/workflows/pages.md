# Workflow: pages

Assembles new static content pages, blog articles, or documentation views.

---

## Steps

1. **Page Creation**:
   - Create HTML page matching master layout and linking shared stylesheets.

2. **SEO & Metadata**:
   - Add unique title, meta description, and OpenGraph tags per page.

3. **Pre-Emit Self-Critique**:
   - `/* Pre-emit critique: P5 H5 E5 S5 R5 V5 D5 */`

- [ ] New page uses semantic HTML5 markup.
